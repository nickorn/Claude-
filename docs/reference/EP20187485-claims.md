## A) Original claims (page 17)

1.	Method for authorizing a third party, the method comprising:

	performing, at a first entity:

		obtaining (1110) a biometric feature of the third party;

		obtaining (1120) a secret value;

		combining (1130) the biometric feature and the secret value so as to obtain a combined secret value;

	performing, at an access controller:

		receiving (1210) the secret value; and

		receiving (1220) the combined secret value;

		processing (1230) the combined secret value using the secret value so as to obtain a decoded biometric feature;

	the method further comprising:

	obtaining (1310) a biometric feature to be verified;

	comparing (1320) the decoded biometric feature with the biometric feature to be verified so as to obtain a comparison result; and

	authorizing (1330) the third party based on the comparison result.

2.	The method of claim 1, wherein comparing the decoded biometric feature with the biometric feature is executed at the access controller (150; 450) .

	authorizing (1330) the third party based on the comparison result such that the third party is authorized for a permission or access at the access controller on behalf of the first entity.

	wherein the biometric feature is transmitted from the access controller (150; 450) to the first entity (100) based on an input signal generated by the third party (250);
